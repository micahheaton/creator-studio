# That storage number is not the scan bill.

**IS02 · Day 2 · IntegratedSOC**

Compressed storage and uncompressed query scans have different billing units.

**Method:** Write down retained data and query scan volume separately.

**Sample result:** 100 GB-month storage estimate · 600 uncompressed GB scanned · Two separate meters.

**Decision:** Apply verified region and subscription rates to each unit.
