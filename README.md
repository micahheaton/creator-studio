# Creator Studio

Three sets of ten public-safe build notes. Each is a different episode with a synthetic fixture. Nothing here is a published website, video, or social post. A fixture pass is not measured time savings or a production outcome.

The offline JavaScript modules in `tools/` export editable sample data and a `run(values)` function per tool. They do not call external APIs. Use Node or import the modules into your own local preview.
